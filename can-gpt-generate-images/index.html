Can GPT generate images and videos? GPT-4o, gpt-oss, coding models and GPT disks

Key takeaways

  • ChatGPT generates and edits images with OpenAI's native image generation, introduced with GPT-4o; free users get a limited allowance.
  • Open-weight gpt-oss models are text-only and cannot generate images.
  • Video comes from Sora, a separate OpenAI model, not from GPT chat models.
  • For coding, use OpenAI's newest coding-tuned or reasoning models, and test against Claude on your own repository.
  • 'GPT disk' in Windows means a GUID Partition Table disk, unrelated to OpenAI's GPT.

Yes, GPT can generate images: ChatGPT creates and edits images with OpenAI's native image generation, which arrived with GPT-4o and is available through the API's image models. GPT chat models do not generate video; OpenAI's Sora does. The open-weight gpt-oss models are text-only. This page covers image generation and free access, gpt-oss, video, the best GPT model for coding and why teams sometimes choose GPT-4.1 over Claude or the reverse, how GPT works in brief, what to do when GPT is down, and the unrelated "GPT disks" in Windows.

Can GPT generate images?

Yes. ChatGPT can generate images from text descriptions and edit uploaded images, using OpenAI's native image generation. Developers access the same capability through OpenAI's image models in the API.

Also asked as: can chat gpt generate images for free

Describe the subject, style, composition, lighting and any text you want in the image, then refine with follow-ups such as "make the background plain white" or "add more space at the top for a title". The model handles text inside images and consistent edits much better than earlier image generators, though it can still misspell or alter small details. Respect copyright and people's likeness, and label AI images when they could be mistaken for real photographs.

Can ChatGPT generate images for free?

Yes, within limits. Free ChatGPT users can generate a limited number of images per day, and paid plans raise those limits. During busy periods, free limits may be reduced.

To get the most from a free allowance, write one detailed prompt instead of many vague attempts, and edit an image with targeted follow-ups rather than regenerating from scratch. Other free options include Gemini, Microsoft Copilot and Designer, which also offer image generation with daily limits. Check each service's current limits, since they change frequently, and review terms for commercial use of generated images.

Can GPT-4o generate images?

Yes. GPT-4o introduced native image generation in ChatGPT in 2025, meaning the model can create images directly as part of a conversation, using context from the chat and uploaded images, rather than handing off to a separate older image model.

Also asked as: can gpt 4o generate images

That integration is why ChatGPT can follow detailed instructions, keep a character consistent across images, and edit specific parts of an uploaded picture. Newer OpenAI models and dedicated image models continue this capability, so the exact model behind image generation in ChatGPT may change over time. In the API, use the current image generation models listed in OpenAI's documentation.

Can gpt-oss generate images?

No. OpenAI's gpt-oss models are open-weight language models for text: reasoning, coding, tool use and writing. They do not generate images and do not take images as input.

Also asked as: can gpt oss generate images

If you want local image generation, use open image models such as Stable Diffusion-family models through tools designed for image generation, on a capable GPU. You can combine them with gpt-oss: let the language model write detailed prompts, then pass them to an image model. For hosted image generation, use ChatGPT or OpenAI's image API, or other providers' image models.

Can GPT generate videos?

GPT chat models do not generate videos. OpenAI's Sora is the video generation model, available through its own app and website for eligible users and regions. ChatGPT can write scripts, storyboards and Sora prompts.

A workflow: plan the video in ChatGPT, generate short clips in Sora from detailed shot prompts, then edit them together with narration and captions in a video editor. ChatGPT can also produce simple slideshow-style videos by writing and running code, but that is not true video generation. Generated videos carry watermarks and provenance signals; label them when publishing.

Which GPT model is best for coding?

Use OpenAI's newest coding-tuned or reasoning models for serious programming, such as the Codex models built for agentic coding, and faster smaller models for quick completions. The best choice changes with each release, so check OpenAI's models page.

More important than the model is the tool: Codex, GitHub Copilot or another agent that reads your repository, runs tests and iterates will outperform pasting code into chat. For a fair comparison, give two or three models the same real task in your own codebase, such as adding an endpoint with tests, and compare how much you had to fix. Keep a project instruction file with build and test commands so any agent works well.

Why choose GPT-4.1 and not Claude?

Teams choose between GPT-4.1 and Claude models based on their own tests, cost, speed, context length, instruction following and which tools they use. GPT-4.1 has been a common default in some coding tools for its speed and instruction following, while Claude models are widely chosen for agentic coding and long, careful work.

Also asked as: why gpt 4.1 and not claude

There is no universal winner. A tool may pick a default model for cost, latency or availability reasons, and you can often switch models in the picker. Model generations move fast, so a comparison from a few months ago may not hold. Run your own evaluation: the same tasks, the same prompts, and a clear score for correctness and edits required.

How does GPT work?

GPT is a transformer language model that generates text by predicting the next token over and over, based on everything before it. It learned language, facts and patterns from large-scale pre-training, then was tuned to follow instructions and be helpful.

Each word piece of your prompt becomes a vector; attention layers relate every token to every other, building context; the final layer gives probabilities for the next token, one is chosen, and the process repeats. ChatGPT adds tools around the model, such as search, code execution and image generation, plus memory and safety systems. Because it predicts plausible text, it can be wrong while sounding confident, so verify important facts.

Why is GPT down?

When ChatGPT or the OpenAI API is not working, first check OpenAI's status page for incidents. If it shows no problems, the cause is usually local: network issues, browser extensions, an expired login, rate limits or very long conversations.

Also asked as: why gpt is down

Steps to try:

  • Check status.openai.com for outages or degraded performance.
  • Refresh, sign out and back in, or try another browser or the app.
  • Start a new conversation if one chat is stuck.
  • Disable VPNs or extensions that interfere.
  • For the API, check error codes: rate limits and server errors need retries with backoff.

For apps that depend on the API, build a fallback to another provider so outages do not stop your users.

What are GPT disks?

In computer storage, a GPT disk uses the GUID Partition Table, a modern partitioning scheme that replaced the older MBR scheme. It has nothing to do with OpenAI's GPT models.

GPT partitioning supports very large disks and many partitions, stores redundant partition tables for resilience, and is required for booting Windows in UEFI mode. In Windows Disk Management, you will see disks labelled GPT or MBR. Converting between them usually requires deleting partitions or using specific tools, so back up data first.
