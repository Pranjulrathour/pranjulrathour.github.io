What is Copilot 365? How Microsoft 365 Copilot works in Excel, Outlook and more

Microsoft 365 Copilot is an AI assistant inside Word, Excel, Outlook and Teams that answers from your work data. How it works and how it differs from Copilot.

Microsoft 365 Copilot, often called Copilot 365, is an AI assistant built into Word, Excel, PowerPoint, Outlook and Teams that answers from your work emails, files, chats and meetings as well as the web. It matters because it is the first AI tool many students meet in an internship or first job. This page explains how it works under the hood, which plans include it, how it behaves in Excel, Outlook and Visual Studio, and how Copilot Studio lets you build your own agents.

What is Copilot 365?

Copilot 365 is Microsoft 365 Copilot: a large language model assistant inside the Microsoft 365 apps that can draft, summarise and analyse using your organisation's content, within the permissions you already have.

Also asked as: how copilot works

You reach it from a Copilot button in each app, or from Copilot Chat in Teams and the Microsoft 365 app. In Word it drafts and rewrites documents; in PowerPoint it builds a deck from a Word file; in Teams it summarises a meeting you missed and lists the action items. What makes it different from a public chatbot is grounding: a question like "what did the client ask for last week?" is answered from your actual emails and meeting transcripts, with references back to the source items, rather than from the model's general knowledge.

How does Copilot work?

Copilot takes your prompt, searches the content you have access to through Microsoft Graph, adds the relevant pieces to the prompt, sends it to a large language model, then checks the answer before showing it.

That is retrieval-augmented generation (RAG) at company scale. The flow:

  • Grounding: Microsoft Graph and the semantic index find relevant emails, files, chats and meetings that your account is permitted to open.
  • Generation: the enriched prompt goes to a large language model hosted within the Microsoft 365 service boundary.
  • Post-processing: responsible-AI and compliance checks run, and the answer returns with citations to the source items.

It is the same pattern I built in RAG.NextUpgrad: retrieve permitted content first, answer only from it, and cite where each claim came from. Answer quality depends on retrieval, so messy, duplicated or over-shared files produce messy answers.

Does Copilot come with Microsoft 365?

Partly. Work accounts get Microsoft 365 Copilot Chat, which is web-grounded, while the full work-grounded Microsoft 365 Copilot is an add-on licence. Consumer plans include some Copilot features in the apps with usage limits.

The practical test is what you see. If Copilot in Word or Outlook can answer questions about your organisation's files and meetings, you have the full licence. If you only get a chat that answers from the web and the files you upload, you have Copilot Chat. Students should check with their college IT team, because institutional plans differ a lot. Plans and included features change regularly, so the current comparison is always on Microsoft's own plan pages rather than in an older article.

What is the difference between Copilot and Microsoft 365 Copilot?

Microsoft Copilot is the free consumer assistant for personal Microsoft accounts, grounded in the web. Microsoft 365 Copilot is the work product, grounded in your organisation's data with enterprise data protection and admin controls.

The brand covers several products, which confuses people:

  • Microsoft Copilot: the consumer app and website, for personal use.
  • Microsoft 365 Copilot: the work assistant across Word, Excel, Outlook and Teams.
  • GitHub Copilot: the coding assistant in VS Code, Visual Studio and JetBrains IDEs.
  • Copilot Studio: a low-code tool for building your own agents.

For work data the difference that matters is protection. Under enterprise data protection, Microsoft states that prompts and responses are not used to train its foundation models and that existing permissions and compliance policies apply.

How does Copilot work in Excel?

Copilot in Excel reads the table you are working in and helps you analyse it: it suggests formulas, adds calculated columns, highlights and sorts data, builds charts and PivotTables, and explains what it found.

Also asked as: how copilot works in excel

Two habits avoid most failures. First, format the data as a table with Ctrl+T and give every column a clear header, because Copilot works on structured ranges. Second, save the workbook to OneDrive or SharePoint, since Copilot relies on the cloud version of the file. Then ask specific questions: "add a column with profit margin as a percentage" works better than "analyse this". Always check the formula it inserts before you trust the numbers; it is a fast first draft, not an auditor. For heavier analysis Copilot can also use Python in Excel to run statistics or forecasts on the table.

How does Copilot work in Outlook?

In Outlook, Copilot summarises long email threads, drafts replies from a short instruction, and coaches you on the tone and clarity of a message before you send it.

Also asked as: how copilot works in outlook

Open a thread and choose the summary option to get the key points and open questions at the top. To reply, type an instruction such as "accept the meeting, ask for the agenda, keep it short" and adjust the length and tone of the draft. Coaching reviews a draft you wrote and suggests changes, which is useful for formal emails to professors or recruiters. With the full licence it can also pull context from related files and meetings. Read every draft before sending: it can confidently state a date or commitment that was never agreed.

How does Copilot work in Visual Studio?

In Visual Studio the assistant is GitHub Copilot, not Microsoft 365 Copilot. It suggests code as you type, answers questions about your solution in a chat window, and in recent versions can make multi-file edits in agent mode.

Also asked as: how copilot works in visual studio

Sign in with a GitHub account that has Copilot access; GitHub offers a free tier with monthly limits and paid plans with more. Inline completions appear as grey text that you accept with Tab. In the chat window, slash commands such as /explain, /fix, /tests and /doc act on the selected code, and # references pull in specific files. Agent mode plans a change, edits several files and runs the build to check itself. The habits that matter are the same as with any assistant: small requests, review every diff, and run the tests.

How does Copilot Studio work?

Copilot Studio is Microsoft's low-code tool for building agents. You give an agent instructions, knowledge sources and actions, and it uses a language model to decide how to answer each message and which action to call.

Also asked as: how copilot studio works

Knowledge can be public websites, SharePoint sites, uploaded files or business data in Dataverse. Actions connect the agent to systems through Power Platform connectors, Power Automate flows or custom APIs, so it can create a ticket or look up an order instead of only chatting. Topics still exist for fixed conversations such as a refund policy. You test the agent in the built-in chat pane, then publish it to Teams, a website or Microsoft 365 Copilot. The design rules are those of any agent: narrow scope, clear instructions and logs you can review.

Is there a tutorial for Copilot in Microsoft 365?

Yes. Microsoft Learn has free training paths for Microsoft 365 Copilot, and the quickest way to learn is one real task a day in the app you already use.

Also asked as: tutorial copilot microsoft 365

A practical first week:

  • Day 1, Teams: ask Copilot to summarise a recorded meeting and list action items with owners.
  • Day 2, Outlook: summarise your longest thread and draft a reply from a one-line instruction.
  • Day 3, Word: turn rough notes into a structured report, then ask for a shorter version.
  • Day 4, Excel: format a dataset as a table and ask three specific analysis questions.
  • Day 5, PowerPoint: create a deck from the Word report and fix it by hand.

Write prompts with a goal, context, the source to use and the format you expect. That structure improves results more than any trick.

Where can I see the Copilot 365 roadmap?

The Microsoft 365 roadmap website lists planned and rolling-out features. Filter it by the Microsoft 365 Copilot product to see what is in development, rolling out or launched, with target months.

Also asked as: roadmap copilot 365

Each roadmap item has an ID, a status and the apps and platforms it affects, so admins use it to prepare training before a feature arrives. Dates move, and some items roll out in stages by region and release channel, so treat a target month as an estimate. For what has already changed, the release notes for Microsoft 365 Copilot on Microsoft Learn are more reliable than news coverage. If you build on top of Copilot with Copilot Studio or plugins, check the roadmap before each project, because a built-in feature may arrive that replaces your custom work.
