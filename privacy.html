Privacy policy — brand-engine

Last updated: 23 September 2026

brand-engine is a private automation tool operated by Pranjul Rathour for personal use. It publishes content the operator has written to accounts the operator owns.

What it accesses

Through Google's Blogger API (scope https://www.googleapis.com/auth/blogger), brand-engine reads and creates posts on the operator's own Blogger blog. It does not access any other Google data, and it does not access any account belonging to anyone else.

What it stores

The only data stored is the OAuth refresh token for the operator's own account, kept in a local configuration file and in an encrypted GitHub Actions secret, used solely to publish scheduled posts.

Sharing

No data is sold, shared, or transferred to any third party. No analytics, tracking, or advertising.

Other users

brand-engine has no users other than its operator and collects no personal information from visitors or readers.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
