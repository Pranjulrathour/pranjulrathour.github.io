Key takeaways

  • Gemini runs mainly on the web, in Chrome and on mobile; on desktops, you can install the web app for an app-like window.
  • Deep Research usually takes several minutes, browsing many sources before writing a cited report.
  • Get a Gemini API key in Google AI Studio and keep it in environment variables.
  • Send files inline for small requests or through the Files API for larger ones; public YouTube URLs work with supported models.
  • 429 errors mean rate or quota limits; add backoff, reduce concurrency or move to a higher tier.

Gemini is Google's AI assistant and model family, used both as an app for research and as an API for developers. For research, Deep Research browses many sources and writes a cited report in minutes. For developers, the Gemini API, accessed with a key from Google AI Studio, handles text, files, images, audio and video. I build document AI and RAG products across providers, so this page covers Gemini on desktop, Gems and Deep Research, model choice, API keys and APIs, sending files and YouTube videos, 429 errors, and Gemini versus Document AI.

Does Gemini have a desktop app?

Gemini is mainly used on the web at gemini.google.com, inside Chrome, and through Android and iOS apps. On Windows and macOS, you can install the web app from Chrome as an app, which gives it its own window and taskbar icon.

Google also integrates Gemini into Chrome, Workspace apps such as Gmail and Docs, and Android. Check Google's official announcements for any native desktop apps in your region, and avoid third-party "Gemini desktop" downloads that are not from Google, since unofficial apps can misuse your account. For developers, Gemini is also available through command-line tools and IDE extensions.

Can a Gemini Gem do Deep Research?

Gems are custom versions of Gemini with saved instructions and files, while Deep Research is a separate research mode. Depending on your plan and current features, you may be able to combine them; otherwise, run Deep Research and include your Gem's instructions in the request.

A practical workaround: keep your research brief, such as audience, scope, sources to prioritise and report structure, in a document, and paste it when starting Deep Research. After the report is generated, open your Gem to refine, summarise or reformat it. Features change often, so check Gemini Apps Help for the current relationship between Gems and Deep Research.

How long does Gemini Deep Research take?

Deep Research usually takes several minutes, often around five to fifteen, depending on the question's complexity, how many sources it browses and system demand. It first shows a research plan you can edit, then searches and reads, then writes a report.

You can leave and come back; Gemini notifies you when the report is ready. Broad questions take longer and produce longer reports, so narrow the scope for faster, more focused results. Reports include citations, and you should open key sources to verify claims before relying on them. Deep Research usage is limited per day depending on your plan.

Which Gemini model is best for research?

For research, use the most capable reasoning model available on your plan, typically the latest Pro model, together with Deep Research for multi-source reports. Faster Flash models suit quick lookups and summaries.

Model names change with each release, so choose by tier: Pro for complex analysis, long documents and careful reasoning; Flash for speed and everyday tasks; lightweight models for high-volume API work. For academic or professional research, combine Gemini with primary sources: verify citations, read the original papers and note publication dates. No model replaces checking evidence yourself.

How do I get a Gemini API key from Google AI Studio?

Sign in to Google AI Studio with your Google account, open the API keys section, and create a key, which links to a Google Cloud project. Copy it once and store it securely in an environment variable or secrets manager.

Also asked as: how to get gemini api key from google ai studio

Then call the API with Google's SDK:

from google import genai
client = genai.Client()   # reads the GEMINI_API_KEY environment variable
resp = client.models.generate_content(model="gemini-2.5-flash", contents="Explain RAG briefly.")
print(resp.text)

Never put keys in front-end code or public repositories; route calls through your server. Restrict and rotate keys if one leaks. Free tier keys have rate limits suitable for development.

What are the Gemini APIs?

The Gemini API gives programmatic access to Gemini models through Google AI Studio's endpoint, and the Vertex AI Gemini API offers the same models within Google Cloud with enterprise controls. Both support text generation, multimodal inputs, function calling, structured output and embeddings.

Also asked as: what are gemini apis

Additional capabilities include the Files API for uploading media, context caching for repeated long prompts, batch processing at lower cost, a Live API for real-time voice and video interactions, grounding with Google Search, and code execution. Choose AI Studio's API for quick development and smaller projects, and Vertex AI when you need Google Cloud security, compliance, regional controls and enterprise billing.

How do I send files to Gemini models through the API?

For small files, include the bytes inline in the request with the correct MIME type. For larger files or reuse across requests, upload with the Files API and reference the returned file in your prompt.

Also asked as: how can i send files to google's gemini models via api calls

doc = client.files.upload(file="report.pdf")
resp = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=[doc, "Summarise the key findings with page references."])
print(resp.text)

Gemini reads PDFs, images, audio and video. Uploaded files are stored temporarily, so re-upload for long-term use. For document extraction, ask for structured JSON with a schema and validate it, as DocuLens AI does for its document checks.

Can the Gemini API watch YouTube videos?

Yes, supported Gemini models accept public YouTube URLs as video input, so you can ask for summaries, timestamps or answers about a video's content. Private and unlisted videos are not supported, and limits apply to video length per request.

Also asked as: can gemini api watch youtube videos

Pass the URL as file data in your request, along with your question. For long videos, ask about specific segments with timestamps. Gemini processes both visual frames and audio, so it can describe what is shown as well as what is said. Respect copyright and YouTube's terms when processing videos, especially for commercial use.

Why does my code get 429 quota exceeded errors from the Gemini API?

A 429 error means you exceeded a rate limit or quota: too many requests per minute, too many tokens per minute or too many requests per day for your tier. Streaming interfaces and generative UI frameworks can trigger extra calls without you noticing.

Also asked as: why does my code send 429 quota exceeds on google gemini api with generative ui

Fixes:

  • Add exponential backoff with retries on 429 responses.
  • Reduce concurrency and avoid duplicate calls from UI re-renders.
  • Cache results for repeated prompts.
  • Use batch processing for bulk jobs.
  • Enable billing or request higher limits for production.
  • Check the rate limits page for your model and tier.

Log every API call during development to spot unexpected request bursts.

What is the difference between Gemini and Document AI?

Gemini is a general multimodal model that can read and reason about documents through prompts. Document AI is Google Cloud's specialised document processing service, with OCR, form parsing, layout analysis and pretrained or custom extractors that return structured fields.

Also asked as: gemini vs document ai

Choose Document AI for high-volume, standardised extraction where consistent schemas, confidence scores and enterprise workflows matter, such as invoices and forms. Choose Gemini for flexible understanding, summarisation and questions across varied documents, with structured output for extraction. Many pipelines combine them: OCR and layout from a document service, then a language model for interpretation, validated against schemas before results are trusted.
