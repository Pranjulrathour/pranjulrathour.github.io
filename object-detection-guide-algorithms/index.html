Object detection: best algorithms, segmentation, OBB, VLMs, labelling, drift, roadmap

Key takeaways

  • YOLO suits real-time detection, transformer detectors lead accuracy, and open-vocabulary models handle arbitrary classes.
  • Detection draws boxes, semantic segmentation labels pixels, and instance segmentation separates each object's mask.
  • Oriented bounding boxes fit rotated objects in aerial and document images.
  • Model-assisted labelling with tools like CVAT, Label Studio and Grounding DINO speeds annotation.
  • Monitor drift signals and trigger reviewed retraining pipelines when thresholds are crossed.

Object detection finds objects in images or video and marks each with a bounding box and class label, such as person, car or defect. It powers counting, tracking, inspection and safety systems. I built FaceVision, which runs face detection in the browser with ONNX Runtime Web, so this page covers the best detection algorithms, examples, detection versus segmentation, oriented boxes and VLMs, easy annotation, YOLOv3 versus RetinaNet, retraining on data drift, a roadmap and courses.

What is the best object detection algorithm?

There is no single best. For real-time detection, recent YOLO models are the practical default. For maximum accuracy, transformer detectors such as RT-DETR, RF-DETR and DINO lead benchmarks. For arbitrary named objects, open-vocabulary detectors like Grounding DINO or YOLO-World work without retraining.

Choose by constraints: latency and hardware, number of classes, object size, licence and available training data. Two-stage detectors such as Faster R-CNN remain solid for small objects and research baselines. Edge devices favour small YOLO variants exported to ONNX or TensorRT, while servers can afford larger transformers. Always fine-tune and benchmark two or three candidates on your own validation set, measuring mean average precision and latency on target hardware, before committing.

What are some examples of object detection?

Examples include detecting pedestrians and vehicles for driver assistance, counting people in stores, finding defects on production lines, reading licence plates after locating them, spotting smoke in CCTV, and detecting faces for camera autofocus.

Agriculture uses detection to count fruit and spot pests; retail uses it for shelf monitoring and self-checkout; healthcare uses it to locate nodules or cells in scans; sports analytics tracks players and balls; and wildlife projects count animals in camera trap images. FaceVision uses face detection as the first step before recognition and liveness checks, running in the browser so images never leave the user's device. Detection is often the first stage of larger vision pipelines.

Semantic segmentation vs object detection vs instance segmentation: what differs?

Object detection draws a box around each object with a class label. Semantic segmentation labels every pixel with a class but does not separate individual objects. Instance segmentation does both: it gives each object its own pixel-precise mask.

Also asked as: what is the difference between semantic segmentation, object detection and instance segmentation

For a street photo, detection outputs boxes for each car and person; semantic segmentation colours all car pixels one colour and all road pixels another; instance segmentation outlines car one and car two separately. Panoptic segmentation combines instance masks for countable things with semantic labels for background such as sky and road. Detection is fastest and cheapest to label; segmentation needs pixel-level annotation but gives precise shapes, useful for measurement, robotics and medical imaging.

OBB vs object detection: what is the difference?

Standard object detection uses axis-aligned boxes, parallel to the image edges. Oriented bounding box detection, OBB, predicts rotated boxes with an angle, fitting tightly around objects that are tilted, such as ships, planes or vehicles in aerial images.

Axis-aligned boxes around rotated, elongated objects include lots of background and overlap with neighbours, which hurts accuracy in crowded scenes like parking lots or harbours. OBB models, such as Ultralytics YOLO OBB variants trained on the DOTA aerial dataset, output the box centre, width, height and rotation. Use OBB for satellite and drone imagery, document text lines and packages on conveyors; use standard detection for most natural photos, where objects are usually upright.

VLM vs object detection: which should you use?

Use a dedicated object detector when you need fast, consistent boxes for known classes at scale, especially in real-time video. Use a vision-language model when you need flexible understanding, open-ended questions or descriptions, and can accept slower, less precise localisation.

Some VLMs, such as Qwen2.5-VL and Florence-2, can output bounding boxes from text prompts, which helps prototyping and rare classes without training data. However, detectors trained on your data are usually far more accurate, faster and cheaper per image. A strong hybrid pattern: use a VLM to auto-label initial data or handle rare queries, then train a compact detector for production. Evaluate both on the same labelled set before deciding.

Are there easy ways to create annotated training images for object detection?

Yes. Use annotation tools such as Label Studio, CVAT or Roboflow Annotate, and speed them up with model-assisted labelling: a pretrained or open-vocabulary detector proposes boxes, and you correct them instead of drawing every box.

Also asked as: are there any easy ways to create annotated training images for object detection

Workflow: collect varied images matching real conditions; label 100 to 200 carefully to start; train a quick model; use it to pre-label the next batch; correct and repeat. Tools like Grounding DINO and Segment Anything can generate boxes and masks from text prompts. Write clear labelling guidelines, such as whether to box partly hidden objects, and review a sample for consistency. Export in the format your trainer expects, such as YOLO text files or COCO JSON.

What are the main differences between YOLOv3 and RetinaNet?

Both are one-stage detectors from 2017 to 2018. RetinaNet introduced focal loss to handle the imbalance between few objects and many background locations, using a ResNet backbone with a Feature Pyramid Network. YOLOv3 used a Darknet-53 backbone with predictions at three scales.

Also asked as: what are the main differences between yolov3 and retinanet object detection algorithms

At release, RetinaNet achieved higher accuracy, particularly with large backbones, while YOLOv3 was much faster, making it popular for real-time applications. YOLOv3 used binary cross-entropy for class predictions, allowing multi-label outputs, and anchor boxes from k-means clustering. Focal loss became widely adopted, and later YOLO versions borrowed ideas such as feature pyramids and improved losses. Today both are mostly historical baselines; modern YOLO and transformer detectors outperform them on accuracy and speed.

How do you trigger retraining for object detection models when data drifts?

Monitor signals that indicate drift: input statistics such as brightness and image embeddings, prediction confidence distributions, class frequencies and, where possible, accuracy on a labelled sample. When metrics cross thresholds, trigger a pipeline that collects, labels and retrains.

Also asked as: how to automatically trigger model retraining for object detection models in case of data drift

Implementation: log embeddings and predictions; compare recent windows with a reference set using drift detectors from libraries such as Evidently or Alibi Detect; schedule checks in an orchestrator like Airflow or Kubeflow; and when drift is confirmed, sample low-confidence images for labelling, retrain from the latest checkpoint, evaluate against a fixed test set plus new data, and deploy gradually with a canary release. Keep humans approving promotions, since automatic retraining can silently amplify labelling mistakes.

What is an object detection roadmap?

Learn Python, NumPy and OpenCV; then CNN fundamentals and transfer learning; then detection concepts such as anchors, IoU, non-maximum suppression and mean average precision; then train YOLO on a custom dataset; then explore transformers, segmentation and deployment.

Milestones: run a pretrained detector on webcam video; label 200 images and fine-tune a model; evaluate with mAP and a confusion matrix; add tracking with ByteTrack to count objects; export to ONNX and run it on a CPU, phone or browser; and compare a YOLO model with RT-DETR on your data. Finish with a deployed project solving a real problem, such as counting vehicles or detecting defects, documented with metrics.

What is a good object detection course or tutorial?

Strong options include Ultralytics' documentation and guides for hands-on YOLO training, Stanford CS231n lectures on detection and segmentation, Hugging Face's computer vision course, and Roboflow's notebooks covering many models end to end.

Pair a course with a project from the first week: choose objects you care about, collect and label images, train, and evaluate. Read key papers as you go: Faster R-CNN, YOLO, RetinaNet's focal loss and DETR. Practise deployment too, exporting a model to ONNX and running it in a simple web app, since employers value people who can ship models, not only train them. Keep notes of experiments and results to build intuition quickly.
