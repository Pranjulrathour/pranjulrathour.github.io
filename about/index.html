Who is Pranjul Rathour?

Pranjul Rathour is a GenAI engineer from Kanpur, Uttar Pradesh, who ships production AI systems: RAG pipelines, fine-tuned LLMs, hybrid retrieval and multi-modal apps across vision, speech and OCR, architected end to end from ingestion to deployment. He leads engineering at SCULT INDIA, founded the TechVerse Enclave developer community, and speaks and judges at college hackathons.

What has he built?

Five production AI applications at NextUpgrad Web Solutions between February and July 2026, each shipped end to end with Docker, CI/CD, structured logging and metrics.

Project What it does Code
RAG.NextUpgrad Production RAG with hybrid dense + BM25 retrieval, re-ranking, streaming cited answers and a confidence gate that refuses weak-evidence answers. Runs in about 220 MB on a free tier. GitHub
FineTune Studio QLoRA fine-tuning from the browser with live training telemetry over WebSockets and base-vs-fine-tuned evaluation. GitHub
DocuLens AI Groq-powered invoice and contract extraction with schema validation and deterministic compliance scoring. GitHub
FaceVision Browser-only face detection, recognition and liveness with ONNX Runtime Web; the server stores embeddings, never images. GitHub
OCR & Speech Workspace Mistral-powered page-batched PDF OCR, live speech-to-text and document-scoped RAG chat with page citations. GitHub

At SCULT INDIA, since 2024, he leads engineering, architecture, UI/UX, deployment and client delivery for a 14-member cross-functional team, and designed SCULT Studio CRM, the internal platform for projects, clients and operations. Earlier products include Vaidya AI, Annapurna, Super Digital Library and client sites for Nuclear Pest Goa, Gloss Digital Entertainment and Passionate Records. The full list is on the portfolio.

How does he write these pages?
