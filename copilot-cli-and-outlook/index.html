What is Copilot CLI, and why is Copilot not showing in Outlook?

GitHub Copilot CLI brings Copilot's agent to your terminal. Plus how to fix Copilot missing in Outlook, what it does there, and what Copilot skills are.

Key takeaways

  • Copilot missing in Outlook is almost always a licence, account, version or admin policy issue, in that order.
  • In classic Outlook, update Microsoft 365 Apps to a current build before anything else.

Copilot CLI is GitHub Copilot's coding agent for the command line: you run it in a project folder, describe a task, and it reads code, edits files and runs commands with your approval. Separately, if Copilot is not showing in Outlook, the cause is nearly always the licence, the signed-in account, an outdated Outlook version or an admin policy. This page covers the CLI, how to fix Copilot missing from new and classic Outlook, what Copilot does in Outlook including scheduling, what Copilot skills are, and a short tutorial for Copilot's agents.

What is Copilot CLI?

GitHub Copilot CLI is a terminal application that brings GitHub Copilot's agent to the command line. It can explain a codebase, write and edit files, run shell commands and work with GitHub, asking for permission before it acts.

You install it with npm and start it inside a repository:

npm install -g @github/copilot
cd my-project
copilot

Sign in with a GitHub account that has Copilot access, then type a request such as "find why the login test fails and fix it". It shows the commands and edits it wants to make, and you approve or reject each one. It can connect to extra tools through MCP servers. Treat it like any agent: small tasks, review the diff, run the tests, commit often.

Does Copilot have a CLI?

Yes. GitHub Copilot has a CLI, the Copilot CLI agent, and Copilot features are also available in terminals inside VS Code and other editors. Microsoft 365 Copilot does not have a general-purpose command line for end users.

Also asked as: do copilot have cli

Before the current Copilot CLI, GitHub offered an extension for the GitHub CLI, gh copilot, that suggested and explained shell commands. The newer Copilot CLI is a full agent that can change files and run multi-step tasks. If you prefer a terminal workflow, other coding agents work similarly: OpenAI's Codex CLI and Anthropic's Claude Code. All of them follow the same safety habits: run them in a project under version control, read every command before approving it, and never let them handle secrets.

Why is Copilot not showing in Outlook?

Usually because the account you are signed into does not have a Copilot licence, Outlook is out of date, or your organisation has not enabled Copilot. Personal Outlook.com accounts and work accounts also show Copilot differently.

Also asked as: why copilot is not showing in outlook

Check in this order:

  • Licence: your work or school account needs Microsoft 365 Copilot for the full in-Outlook features; Copilot Chat may be all you have.
  • Account: make sure Outlook is signed in with the licensed account, not a personal one.
  • Version: update Outlook; new features reach current builds first.
  • Admin policy: admins can turn Copilot features off or roll them out in stages.
  • Restart: sign out of Office, sign in again and restart Outlook after a new licence is assigned.

If colleagues with the same licence see it and you do not, ask IT to check your licence assignment.

Why is Copilot not showing in classic Outlook?

Classic Outlook for Windows shows Copilot only on recent versions of Microsoft 365 Apps. If you are on an older build or a slow update channel, Copilot features may be missing even with a valid licence.

Also asked as: why is copilot not showing in outlook classic

Go to File, then Office Account, then Update Options, and choose Update Now. Check which update channel you are on; organisations on a semi-annual channel get features months later than those on the current channel. Copilot features have generally appeared in the new Outlook and Outlook on the web first. If your organisation allows it, try the new Outlook toggle or Outlook on the web: if Copilot appears there, the problem is your classic Outlook build, not your licence.

Why is the Copilot icon not showing in Outlook?

If you have the licence and an up-to-date Outlook but no icon, the button is often hidden by the ribbon layout or not pinned. Copilot can also appear in different places depending on whether you are reading or writing an email.

Also asked as: why is copilot icon not showing in outlook

Try these:

  • Switch between the simplified and classic ribbon, or use the "more options" menu on the ribbon, where overflow buttons hide.
  • Look inside a message: summary options appear at the top of a thread, and drafting options appear in the compose window.
  • In the new Outlook and on the web, check the app bar for the Copilot icon and pin it.
  • Use "Customise ribbon" to add the Copilot button back if it was removed.

If the icon still does not appear, the feature is probably not enabled for your account yet.

How does Copilot work in Outlook?

Copilot in Outlook uses a large language model to summarise email threads, draft replies and new emails from a short instruction, and coach you on tone and clarity. With a full licence it can also use context from your other work content.

When you open a long thread, the summary gives the key points, decisions and open questions. To draft, type an instruction such as "politely decline, suggest next Tuesday instead" and adjust the length and tone. Coaching reviews your own draft for tone, reader sentiment and clarity. Copilot works within your permissions, so it only uses mail and files your account can already open. Read every draft before sending: it can state a date, figure or commitment that nobody agreed to.

How does Copilot simplify scheduling in Outlook?

Copilot can turn an email thread into a meeting: it suggests times based on attendees' availability, drafts the invitation with an agenda drawn from the thread, and saves you switching to the calendar.

From a thread, use the scheduling option, review the proposed attendees and times, then edit the agenda Copilot drafted before sending. It can also help you prepare by summarising the related emails and files before the meeting. Availability depends on everyone's calendars being shared within your organisation, so external guests may still need a manual poll. Exact options vary by Outlook version and licence, and Microsoft adds scheduling features over time, so check what your version shows.

Is there a tutorial for Copilot in Outlook?

Yes. Microsoft's support and training pages have step-by-step guides, and the fastest way to learn is to use Copilot on your own inbox for a week with one feature a day.

Also asked as: tutorial copilot outlook

A practical sequence:

  • Day 1: summarise your longest thread and check the summary against the emails.
  • Day 2: draft a reply from a one-line instruction, then edit it into your own voice.
  • Day 3: write a draft yourself and use coaching to improve it.
  • Day 4: ask Copilot to find what a colleague asked you for last week.
  • Day 5: schedule a meeting from a thread and review the agenda it proposes.

Write instructions with the goal, the audience and the tone, for example "reply to my professor, formal, confirm the submission date".

What are Copilot skills?

Skills are packaged capabilities that an AI agent can load when a task needs them: instructions, examples and sometimes scripts for a specific job, such as running your project's tests or following your design system. GitHub Copilot's agents support them.

A skill usually lives as a folder with a short description file that says what it does and when to use it, plus any supporting files. The agent reads only the descriptions up front and loads a skill's full contents when a request matches, which keeps the context small and focused. That is different from tools, which are functions the agent can call, and from MCP servers, which connect it to outside systems. Good skills are narrow, clearly described and tested, like good functions. In Microsoft 365, "skills" is also used loosely for the actions an agent built in Copilot Studio can perform.

Is there a tutorial for the Copilot agent?

Yes. The quickest start is agent mode in VS Code: open Copilot Chat, switch to agent mode, and give it a small, testable task. On GitHub, you can also assign an issue to Copilot and review the pull request it opens.

Also asked as: tutorial copilot agent

A first session in VS Code:

  • Open a repository with tests and start Copilot Chat in agent mode.
  • Add a .github/copilot-instructions.md file with build commands and coding rules.
  • Ask: "Add input validation to the signup endpoint, write tests, run them and fix failures."
  • Review each edit and terminal command before approving.
  • Read the final diff and run the tests yourself.

For the GitHub coding agent, write the issue like a ticket for a new teammate: goal, files involved, acceptance criteria. Then review its pull request as carefully as any human's.
