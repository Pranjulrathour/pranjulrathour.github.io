Monitoring an AI app in production on a student budget

A student's deployed AI project silently failed for three days before anyone noticed — the provider's API key had expired and every request was returning an error nobody was watching for.

A minimal setup that catches this

  • A free-tier uptime checker that pings your health endpoint every few minutes and alerts on failure.
  • Error-rate logging with a threshold alert (many free logging services support this) — not just raw logs nobody reads.
  • A simple daily count of successful vs failed LLM calls, even just written to a log line you can grep.

The one alert that matters most

An alert on API authentication failures specifically — an expired or rotated key is one of the most common and most silent production failures in a student project, and it's trivial to detect if you're watching for it.
