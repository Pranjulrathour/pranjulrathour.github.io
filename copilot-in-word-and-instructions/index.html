How to use Copilot in Word, why it is missing, and writing copilot-instructions.md files

Key takeaways

  • Copilot in Word drafts, rewrites, summarises and answers questions about documents, using your files when allowed.
  • You need a Microsoft 365 plan that includes Copilot, the latest Word, and files saved in OneDrive or SharePoint.
  • If Copilot is missing, update Word, sign in with the licensed account and check privacy and admin settings.
  • For GitHub Copilot, put repository instructions in .github/copilot-instructions.md.
  • Good instruction files are short, specific and current; long, vague rules get ignored by any AI assistant.

To use Copilot in Word, open a document in a Word version with Copilot enabled and select the Copilot icon on the Home ribbon or in the margin; then ask it to draft, rewrite, summarise or answer questions about the document. It needs a Microsoft 365 plan that includes Copilot and the right account sign-in. Developers searching "Copilot instructions" mean something else: instruction files that guide GitHub Copilot in code repositories. I use both, so this page covers Copilot in Word and how to write instruction files for coding assistants.

How do I use Copilot in Word?

Open Word, start a new document or open an existing one, and select Copilot. For a new document, describe what you want, such as "Draft a two-page project proposal for a campus recycling app", optionally referencing files. For existing text, select it and ask Copilot to rewrite, shorten or change tone.

Also asked as: how to copilot in word · can you use copilot in word

Useful actions:

  • Draft from a prompt or from referenced files.
  • Rewrite selected paragraphs in a different tone.
  • Summarise a long document into key points.
  • Ask questions about the document, such as deadlines mentioned.
  • Convert text into a table.

Always review drafts for accuracy, since Copilot can invent details.

How does Copilot work in Word?

Copilot in Word sends your prompt, plus relevant document content and, with permission, content from referenced files in your Microsoft 365 account, to large language models running in Microsoft's cloud, then inserts or displays the generated text for you to keep, edit or discard.

For organisations, Microsoft 365 Copilot respects existing permissions: it only uses files the signed-in user can access, and enterprise data protections apply under work accounts. Copilot does not automatically change your document; you choose what to insert. Version history lets you restore previous text if an edit goes wrong. For academic work, check your institution's rules on AI assistance and disclose its use where required.

Can I use Copilot in Word?

You can if you have a Microsoft 365 plan that includes Copilot, either a personal or family subscription where Copilot is offered, or a work or school account with a Microsoft 365 Copilot licence, and you use a supported version of Word.

Availability varies by plan, region and account type, and features differ between consumer and business versions. Students should check whether their institution's licence includes Copilot. Without access, you can still use the free Copilot app or other AI assistants to draft text, then paste it into Word, though without direct document integration.

Where do I find Copilot in Word?

In supported versions, the Copilot button appears on the Home tab of the ribbon, and a Copilot icon may appear in the margin next to your text or when you start a new document. Selecting text often shows a Copilot option for rewriting.

Also asked as: where to find copilot in word

If you open Word for the web, Copilot appears in similar places. On mobile versions, availability is more limited. If you see no Copilot button at all, the cause is usually licensing, the wrong signed-in account, an outdated Word version, or settings, covered in the next section.

Why is Copilot not showing in Word?

Common reasons: your account lacks a Copilot-enabled plan or licence, Word is signed in with a different account, Word is outdated or on a channel without Copilot yet, connected experiences are disabled in privacy settings, or your organisation's administrator has turned Copilot off.

Also asked as: why copilot is not showing in word

Fixes:

  • Check your licence in your Microsoft account or with your IT admin.
  • Sign out and back in with the licensed account.
  • Update Word through File, Account, Update Options.
  • Enable connected experiences in privacy settings.
  • Restart Word and refresh your licence.
  • Save files to OneDrive or SharePoint where required.

What does Copilot in Word focus on?

Copilot in Word focuses on writing tasks: drafting new content, rewriting and editing for tone and length, summarising documents, answering questions about content, and turning text into structured formats such as tables, using your organisation's files as context when permitted.

It is strongest for first drafts, reworking existing text and digesting long documents. It is weaker at precise facts not in your files, specialised formatting and nuanced arguments, where your judgement matters. Treat it as a fast assistant: you remain responsible for accuracy, citations and final quality, especially in academic and professional documents.

Where do I put copilot-instructions.md?

For GitHub Copilot in a repository, create the file .github/copilot-instructions.md at the repository root. Copilot Chat and agent features in supported editors and on GitHub automatically include its contents as context for requests in that repository.

Also asked as: where to put copilot instructions md

VS Code also supports additional instruction files, such as .instructions.md files that apply to specific file patterns, and settings for personal instructions. Keep the main file concise: describe the stack, coding conventions, testing commands and things to avoid. Commit it to the repository so the whole team shares the same guidance.

What is an example of Copilot instructions?

A good instructions file is short and specific about how your project works and what good code looks like.

Also asked as: example copilot instructions

# Project instructions
- Stack: Next.js 15 (App Router), TypeScript, Tailwind, PostgreSQL via Prisma.
- Use server components by default; client components only for interactivity.
- Validate all API input with Zod; never trust client data.
- Write tests with Vitest for new utilities; run `npm test` before finishing.
- Never commit secrets; read config from environment variables.

Add project-specific rules as you notice repeated mistakes, and remove outdated ones. Keep the file under a page or two; very long instruction files dilute the important rules and cost context on every request.

What is an example of Copilot agent instructions?

Agent instructions add guidance on how to work, not just how code should look: how to plan, which commands to run, how to verify changes, and what needs approval. Many tools also read shared files such as AGENTS.md.

Also asked as: example copilot agent instructions

Example rules:

  • Before changing code, read related files and summarise the plan.
  • Make small, focused changes; one feature per pull request.
  • Run lint and tests after edits and fix failures before finishing.
  • Do not modify database migrations or CI configuration without asking.
  • Explain any new dependency and why it is needed.

Clear agent rules reduce wasted iterations and risky changes.

Why does Claude ignore my instructions, and how does CLAUDE.md help?

AI assistants, including Claude, may ignore instructions that are buried in long conversations, contradictory, vague, or stated once early in a session. Over long sessions, earlier instructions compete with newer context. CLAUDE.md files give Claude Code persistent project instructions it loads at the start of each session.

Also asked as: why claude ignores your instructions (and how to fix it with claude.md

To make instructions stick: keep CLAUDE.md concise and specific, explain the reason behind important rules, remove contradictions, put critical rules near the top, and update the file when you notice repeated mistakes. Start fresh sessions for new tasks rather than continuing very long ones. The same principles apply to copilot-instructions.md and other assistants' instruction files.
