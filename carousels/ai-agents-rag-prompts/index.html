The caption

The visitor to this category is mid-build on something real — an autonomous agent, a browser agent, an internal support bot, a RAG pipeline — not asking a chatbot a casual question. The 19 AI Agents & RAG prompts on tools.scult.in are written for that person: design a chunking strategy before writing ingestion code, tune hybrid dense + sparse retrieval from actual query failures, build an eval harness instead of eyeballing answers, build a text-to-SQL agent that can't write to your database, red-team your own system prompt. They come from the same decisions I made shipping RAG.NextUpgrad this year — hybrid retrieval, a confidence gate, 196 tests. Each prompt lists the tool and version it was tested against. Try it free: https://tools.scult.in/prompts/ai-engineering Built entirely solo and free for users, forever.
