What MCP actually is

9 slidesPosted on LinkedIn

MCP — the Model Context Protocol — is the piece that lets an AI agent discover and call your tools mid-conversation, without you writing glue for every AI app. Instead of explaining it abstractly, here's the public MCP server I built for tools.scult.in: one endpoint, no auth, and every tool, prompt, skill and article on the site callable by Claude Code, Cursor, or any MCP client. One line to connect. Swipe for how it works and what I learned building it. Built entirely solo and free for users, forever. If you're a company like Sarvam AI, Vercel, Anthropic that acquires or invests in tools like this, I'd genuinely love to talk — pranjulrathour41@gmail.com.
