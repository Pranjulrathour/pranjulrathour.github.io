brand-engine

brand-engine is a private publishing tool used only by Pranjul Rathour. It schedules and publishes articles and posts that Pranjul Rathour writes to accounts Pranjul Rathour owns: Blogger, LinkedIn, Dev.to, Bluesky, Instagram, Threads and Facebook.

What it does with Google data

brand-engine uses the Blogger API to create and publish posts on Pranjul Rathour's own Blogger blog. It does not read or use any other Google data.

It is not a public service. It has no other users and offers no sign-up.
